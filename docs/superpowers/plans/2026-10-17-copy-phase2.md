# 초안 문구 개선 구현 계획 (2단계)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 첫 초안 문구(`write_copy`)를 프롬프트(2-1)로 먼저 고치고, Codex 교사가 확실히 나을 때만 LoRA SFT(2-2)를 해서, 시험용 상품 30개의 블라인드 비교와 기계 지표로 채택 여부를 정한다.

**Architecture:** 평가 장치 `scripts/finetune/copy_eval.py`가 가상 상품으로 런타임과 똑같이 초안을 만들고(`agent.copy_messages` → `build_sections` → `check_sections`), 기계 지표를 재고, 블라인드 짝을 만든다. 판정은 맥락 없는 새 Claude 서브에이전트가 하고, `score`가 열쇠로 승패를 푼다. 2-2는 `codex_teacher.py copy`가 같은 메시지로 교사 초안을 만들고, 검사를 통과한 초안만 SFT 행이 된다.

**Tech Stack:** 앱은 기존과 같음. 평가·데이터는 `uv run python`. 학습은 `.local/venvs/mlx-vlm`(mlx-vlm 0.7.8). 교사는 Codex CLI(`codex exec`). 판정자는 Agent 도구의 서브에이전트.

**Spec:** `docs/superpowers/specs/2026-10-17-copy-phase2-design.md`

## Global Constraints

- 데이터·초안·짝·열쇠·어댑터·로그는 `.local/finetune/copy/`(git 제외)에 둔다. 상품은 `.local/finetune/judge/products.jsonl`만 쓴다. 사용자 데이터 `projects/`는 쓰지 않는다.
- 문구 메시지는 `agent.copy_messages`로만 만든다. 검사는 `agent.build_sections` → `agent._settle` → `agent.check_sections`로만 한다(런타임과 같은 함수).
- 상품 나누기는 `copy_eval.splits`만 쓴다: 분류마다 id 순서로 개발용 1~6번째, 시험용 13~18번째, 학습용 나머지.
- 시험용 초안은 단계 판정 때만 만들고 연다(2-1에 한 번, 2-2에 한 번). 기준선 `test-base.json`은 2-1 전에 만들어 두기만 하고, 판정 전에는 내용도 지표도 보지 않는다.
- 문구 프롬프트와 교사 지시문 상수에는 개발용·시험용 상품 이름이나 그 초안 문장을 넣지 않는다. 예시는 새로 짓는다.
- 블라인드 판정자는 Agent 도구로 띄운 새 서브에이전트이고, 모델은 **`fable`**(Agent 도구에서 가장 성능 좋은 모델)로 2단계의 모든 비교에서 같게 둔다. 서브에이전트에게는 `brief.md` 경로 하나만 준다. 열쇠, 프롬프트, 스펙, 이 계획은 주지 않는다.
- 합격 기준(스펙 §1):
  - 2-1·2-2 시험 판정: 새 초안 승률 ≥ 0.6(비슷함 제외), 기계 지표가 허용 폭 안, `scripts/eval_tools.py` 도구 11/13 이상·판정 8/8
  - 2-2만: 평균 초안 시간 ≤ 기준선의 1.5배
  - 관문: 교사 승률 ≥ 0.7, 기계 지표가 허용 폭 안
- 허용 폭: 예시 베끼기·상품 간 중복·이름표 제목·지어낸 사실 +0.02, 한자 초안 +1개, 페이지 두께 ×0.9 이상.
- 기준을 바꾸는 일은 사용자가 정한다.
- 초안 만들기는 모두 `--workers 2`로 한다. 초안 시간을 비교하기 때문이다.
- LoRA 학습 중에는 초안·평가를 돌리지 않는다. MLX Serve 재시작은 사용자에게 묻고 한다.
- Codex는 `scripts/finetune/codex_teacher.py`와 `tests/test_finetune.py`만 고치고 git 상태를 바꾸지 않는다. 그 사이 Claude는 두 파일을 건드리지 않는다.
- LangSmith에는 가상 데이터만 간다(`copy_eval`은 `judge_data`를 불러 `pagegen-finetune` 추적을 켠다).
- push·merge는 사용자가 요청할 때만 한다.

## Review Focus

1. **같은 `--out`에 다른 프롬프트·모델·분할로 이어 쓰기:** 두 프롬프트의 초안이 한 파일에 섞이면 비교가 무의미해진다. 이 경우 거부해야 한다(Task 2 `test_resume_refuses_a_file_made_with_another_prompt_or_source`).
2. **JSON을 두 번 못 받았거나 판정이 전부 실패한 초안:** 멈추지 않고 오류로 기록해야 한다. 블라인드 비교에서는 그쪽의 패배로 센다. 실제 사용자는 초안을 못 받기 때문이다(Task 2 `test_draft_records_a_model_failure`, Task 4 `test_a_failed_draft_is_a_forfeit_not_a_pair`).
3. **MLX Serve 목록에 없는 `--model`:** 서버가 이미 올라온 모델로 답하므로 멈춰야 한다(Task 2 `test_drafts_refuse_a_model_the_server_does_not_list`).
4. **판정 파일이 짝을 빠뜨렸거나 A/B/tie 밖의 값을 쓴 경우:** 채점을 거부해야 한다(Task 4 `test_score_counts_wins_ties_and_forfeits`).
5. **다른 `COPY_SYSTEM`으로 검사한 교사 초안:** 그 초안으로 학습 행을 만들면 런타임이 보내지 않는 프롬프트를 가르치게 되므로 거부해야 한다(Task 8 `test_sft_rows_keep_only_clean_teacher_drafts_with_the_runtime_prompt`).

```python
def _clean(section: dict, corpus: str, basis: str, name: str, llm, tally: dict) -> None:
    """Spec §4.1-6 for one model-written section: drop sentences, or replace the headline, failing either check.
    A sentence the judge cannot answer (the 9B sometimes loops until max_tokens) is dropped, not fatal.
    Every dropped text goes to tally["dropped"] with its reason (the phase 2 copy eval reads them)."""
    def reason(text: str) -> str:
        if pg.unsupported_numbers(text, corpus):
            return "number"
        if pg.unsupported_superlatives(text, corpus):
            return "superlative"
        if pg.unsupported_hanja(text, corpus):
            return "hanja"
        if not text.strip():
            return ""
        tally["judged"] += 1
        try:
            return "judge" if judge(llm, text, basis) else ""
        except LLMError:
            tally["failed"] += 1
            return "judge_error"  # unjudged text never reaches the page

    def passes(text: str) -> bool:
        why = reason(text)
        if why:
            tally["dropped"].append({"text": text, "reason": why})
        return not why

    if not passes(section["headline"]):
        section["headline"] = "" if section["kind"] in ("banner", "split") else name  # don't repeat the hero title
    lines = []
    for line in section["body"].splitlines():
        sentences = _sentences(line)
        kept = [s for s in sentences if passes(s)]
        if section["kind"] == "points" and len(kept) < len(sentences):
            continue  # a point cut in half loses its title or its meaning: drop the whole point
        if kept:
            lines.append(" ".join(kept))
    section["body"] = "\n".join(lines)


def check_sections(sections: list[dict], corpus: str, basis: str, name: str, llm) -> tuple[list[dict], dict]:
    """Spec §4.1-6 over a whole draft, in place: (settled sections, tally of judged/failed/dropped).
    Raises LLMError when no judge call succeeded. scripts/finetune/copy_eval.py checks drafts with this same function."""
    tally = {"judged": 0, "failed": 0, "dropped": []}
    for section in sections:
        if section["kind"] not in ("spec_table", "gallery"):  # facts are spec-checked; the gallery title is fixed
            _clean(section, corpus, basis, name, llm, tally)
    if tally["judged"] and tally["failed"] == tally["judged"]:
        raise LLMError("주장 검사를 하지 못해 초안을 만들지 않았습니다. 모델 서버 상태를 확인해 주세요.")
    return _settle(sections), tally
```

def _texts(sections: list[dict]) -> int:
    """What _clean checks one by one: each headline whole, each body sentence by sentence."""
    return sum(bool(s["headline"].strip()) + sum(len(agent._sentences(line)) for line in s["body"].splitlines())
               for s in sections if s["kind"] not in ("spec_table", "gallery"))


def draft(draft_id: str, product: dict, copy_of, judge_llm=llm) -> dict:
    """One draft through the runtime assembly and checks (spec §3.2). A model or judge failure is recorded, not raised."""
    started = time.perf_counter()
    copy, error, result = None, None, {"sections": [], "dropped": [], "sentences": 0, "kept": 0}
    try:
        copy = copy_of(product)
        sections, _ = agent.build_sections(copy, inputs(product)[1], product["name"], PHOTOS)
        sections = agent._settle(sections)
        written = _texts(sections)
        kept, tally = agent.check_sections(sections, f"{product['name']}\n{product['notes']}",
                                           judge_data.basis(product), product["name"], judge_llm)
        result = {"sections": kept, "dropped": tally["dropped"], "sentences": written, "kept": _texts(kept)}
    except llm.LLMError as e:
        error = str(e)
    return {"id": draft_id, "product_id": product["id"], "copy": copy, **result,
            "seconds": round(time.perf_counter() - started, 2), "error": error}


def resume(out: Path, header: dict) -> dict:
    """The drafts file to continue: finished drafts stay, failed ones are made again.
    A file made with another prompt, source or split is refused: mixing them would compare nothing."""
    if not out.exists():
        return {**header, "drafts": []}
    doc = json.loads(out.read_text("utf-8"))
    if any(doc.get(key) != value for key, value in header.items()):
        raise SystemExit(f"{out} was made with another prompt, source or split; use a new --out")
    return {**doc, "drafts": [d for d in doc["drafts"] if d["error"] is None]}


def save(path: Path, doc: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(doc, ensure_ascii=False, indent=1), "utf-8")


def example_units(system: str) -> set[str]:
    """Spec §3.3 example copying: each quoted example of a copy prompt, or any two words in a row of a longer one
    (the baseline's "아침 햇살이 드는 원목 식탁 위" came back as "아침 햇살이 드는 주방")."""
    units: set[str] = set()
    for quote in re.findall(r'"([^"\n]+)"', system):
        words = quote.split()
        units |= {" ".join(words[i:i + 2]) for i in range(len(words) - 1)} if len(words) > 2 else {quote.strip()}
    return {u for u in units if u}


def _strings(value) -> list[str]:
    if isinstance(value, dict):
        return [s for v in value.values() for s in _strings(v)]
    if isinstance(value, list):
        return [s for v in value for s in _strings(v)]
    return [value] if isinstance(value, str) else []


def _headings(copy: dict) -> list[str]:
    """Model-written section headings outside the notice."""
    parts = [copy.get(name) if isinstance(copy.get(name), dict) else {} for name in ("hero", "banner", "points", "scene")]
    found = [p.get("headline", "") for p in parts] + [d.get("headline", "") for d in copy.get("details") or []
                                                        if isinstance(d, dict)]
    return [str(h).strip() for h in found if str(h).strip()]


def metrics(drafts: list[dict], quoted: set[str]) -> dict:
    """Spec §3.3 over the drafts that were made; `quoted` is the union of both prompts' example_units."""
    ok = [d for d in drafts if d["error"] is None]
    n = len(ok) or 1
    per_draft = [set(judge_data.copy_sentences(d["copy"])) for d in ok]
    shared = Counter(s for sentences in per_draft for s in sentences)
    occurrences = sum(len(sentences) for sentences in per_draft) or 1
    heads = [h for d in ok for h in _headings(d["copy"])]
    return {
        "drafts": len(ok), "failed": len(drafts) - len(ok),
        "example_copy": round(sum(any(q in s for s in _strings(d["copy"]) for q in quoted) for d in ok) / n, 3),
        "duplicates": round(sum(shared[s] >= 3 for sentences in per_draft for s in sentences) / occurrences, 3),
        "label_headings": round(sum(_norm(h) in _LABELS for h in heads) / (len(heads) or 1), 3),
        "hanja": sum(bool(pg._HANJA.search(json.dumps(d["copy"], ensure_ascii=False))) for d in ok),
        "dropped": round(sum(len(d["dropped"]) for d in ok) / (sum(d["sentences"] for d in ok) or 1), 3),
        "thickness": round(sum(d["kept"] for d in ok) / n, 2),
        "seconds": round(sum(d["seconds"] for d in ok) / n, 2),
    }

    else:

                for pid in sorted(ids)]

    todo = [t for t in todo if t[0] not in done]
    with ThreadPoolExecutor(args.workers) as pool:
        for n, made in enumerate(pool.map(lambda t: draft(t[0], items[t[1]], t[2]), todo), 1):
            doc["drafts"].append(made)
            if n % 10 == 0:
                save(args.out, doc)
                print(f"{n}/{len(todo)} drafts", flush=True)
    save(args.out, doc)
    print(json.dumps(metrics(doc["drafts"], example_units(doc["system"])), ensure_ascii=False))
    return 0

    system, user = copy_eval.messages(product)
    prompt = f"{system['content']}\n\n{user['content']}\n\n{COPY_SUFFIX}"

def validate_copy(payload: dict[str, Any]) -> dict[str, Any]:
    points = payload.get("points")
    items = points.get("items") if isinstance(points, dict) else None
    if not isinstance(items, list) or len(items) != 3:
        raise BatchValidationError("points.items는 3개여야 함")
    if payload.get("details"):
        raise BatchValidationError("사진 설명이 없으므로 details는 빈 목록이어야 함")
    hero = payload.get("hero")
    if not isinstance(hero, dict) or not str(hero.get("headline") or "").strip():
        raise BatchValidationError("hero.headline이 비어 있음")
    return payload


def run_copy(workers: int, split: str, rounds: int, feedback_path: Path | None) -> int:
    products = {row["id"]: row for row in _load_jsonl(PRODUCTS_PATH)}
    ids = copy_eval.splits(products)[split]
    out_path = COPY_DIR / f"teacher-{split}.jsonl"
    existing = _load_jsonl(out_path)
    done = {row["id"] for row in existing}
    if feedback_path:
        feedback = json.loads(feedback_path.read_text(encoding="utf-8"))
        tasks = [(f"{pid}-retry", pid, feedback[pid]) for pid in ids if pid in feedback]
    else:
        tasks = [(f"{pid}-r{n}", pid, []) for pid in ids for n in range(1, rounds + 1)]
    tasks = [task for task in tasks if task[0] not in done]
    stats = RunStats()

    def execute(task: tuple[str, str, list[str]]) -> dict[str, Any] | None:
        draft_id, pid, flagged = task
        result, error = call_codex("copy", copy_prompt(products[pid], flagged), validate_copy, stats, draft_id)
        if result is None:
            print(f"[copy] {draft_id}: 건너뜀 — {error}", flush=True)
            return None
        return {"id": draft_id, "product_id": pid, "copy": result, "teacher": "codex"}

    with concurrent.futures.ThreadPoolExecutor(max_workers=workers) as pool:
        rows = [row for row in pool.map(execute, tasks) if row]

RUBRIC = """채점 기준(위에서부터 차례로 따집니다. 앞 기준에서 차이가 분명하면 그 쪽이 이깁니다):
1. basis에 없는 제품 사실(기능·성능·소재·성분·인증·효능·관리법·수치)을 말하는 쪽이 집니다. 분위기·장면·느낌을 꾸미는 말은 제품 사실이 아닙니다.
2. 이 분류의 상품을 사고 싶어지게 하는가: 고객이 얻는 혜택이 분명한가, 다른 상품에도 붙일 수 있는 말이 아니라 이 상품만의 개성이 있는가.
3. 분류에 어울리는 말투인가.
4. 자연스러운 한국어인가: 반복, 베낀 듯한 상투구, 내용 없는 이름표 제목이 없는가.
모든 기준에서 비슷하면 tie입니다."""


def render(sections: list[dict]) -> str:
    return "\n".join(f"[{s['kind']}] {s['headline']}".rstrip() + (f"\n{s['body']}" if s.get("body") else "")
                     for s in sections)


def make_pairs(new: dict, old: dict, items: dict[str, dict], seed: int = 0) -> tuple[list[dict], dict]:
    """Blind A/B pairs (spec §3.4), new on a seeded random side. A draft that failed loses its product (a forfeit)."""
    def by_product(doc: dict) -> dict[str, dict]:
        out: dict[str, dict] = {}
        for d in doc["drafts"]:
            if d["product_id"] in out:
                raise ValueError(f"{d['product_id']}: one draft per product for a blind pair")
            out[d["product_id"]] = d
        return out

    a, b = by_product(new), by_product(old)
    if set(a) != set(b):
        raise ValueError("new and old drafts cover different products")
    rng, pairs, sides, forfeits = random.Random(seed), [], {}, {}
    for pid in sorted(a):
        side = "A" if rng.random() < 0.5 else "B"
        n, o = a[pid], b[pid]
        if n["error"] or o["error"]:
            if not (n["error"] and o["error"]):
                forfeits[pid] = "new" if n["error"] else "old"
            continue
        first, second = (n, o) if side == "A" else (o, n)
        pairs.append({"id": pid, "category": items[pid]["category"], "basis": judge_data.basis(items[pid]),
                      "A": render(first["sections"]), "B": render(second["sections"])})
        sides[pid] = side
    return pairs, {"new_side": sides, "forfeits": forfeits}


def brief(pairs_path: Path, verdicts_path: Path) -> str:
    return f"""# 상세페이지 문구 블라인드 비교

`{pairs_path}`의 각 줄은 상품 하나입니다: id, category, basis(판매자 설명과 사진에서 보이는 것), A와 B(같은 상품의 두 문구).
줄마다 A와 B를 아래 기준으로 비교해 더 나은 쪽을 고르세요. 이 파일 말고는 아무 파일도 읽지 마세요.

{RUBRIC}

결과는 `{verdicts_path}`에 한 줄에 JSON 하나로 쓰세요: {{"id": "...", "winner": "A" | "B" | "tie", "reason": "한 줄 이유"}}.
모든 id에 답하세요. 끝나면 A·B·tie 개수만 보고하세요.
"""


def tally(verdicts: list[dict], key: dict) -> dict:
    sides, got = key["new_side"], {v["id"]: v["winner"] for v in verdicts}
    if set(got) != set(sides) or not set(got.values()) <= {"A", "B", "tie"}:
        raise ValueError("verdicts must answer every pair with A, B or tie")
    forfeits = list(key["forfeits"].values())
    wins = sum(w == sides[i] for i, w in got.items()) + forfeits.count("old")
    losses = sum(w not in (sides[i], "tie") for i, w in got.items()) + forfeits.count("new")
    ties = sum(w == "tie" for w in got.values())
    return {"wins": wins, "losses": losses, "ties": ties,
            "win_rate": round(wins / (wins + losses), 3) if wins + losses else 0.0}


def compare(new_m: dict, old_m: dict) -> dict[str, bool]:
    """Spec §3.3: each metric may get worse only by its tolerance."""
    ok = {k: new_m[k] - old_m[k] <= tolerance + 1e-9 for k, tolerance in TOLERANCE.items()}
    ok["thickness"] = new_m["thickness"] >= old_m["thickness"] * MIN_THICKNESS - 1e-9
    return ok


def cmd_pairs(args) -> int:
    key_path = ROOT / "keys" / f"{args.name}.json"
    if key_path.exists():  # a reshuffle after the verdicts would no longer match them
        raise SystemExit(f"{args.name} already has pairs; pick a new --name")
    new, old = (json.loads(path.read_text("utf-8")) for path in (args.new, args.old))
    pairs, key = make_pairs(new, old, products())
    blind = (ROOT / "blind" / args.name).resolve()
    blind.mkdir(parents=True, exist_ok=True)
    (blind / "pairs.jsonl").write_text("".join(json.dumps(p, ensure_ascii=False) + "\n" for p in pairs), "utf-8")
    (blind / "brief.md").write_text(brief(blind / "pairs.jsonl", blind / "verdicts.jsonl"), "utf-8")
    key_path.parent.mkdir(parents=True, exist_ok=True)
    key_path.write_text(json.dumps({"new": str(args.new), "old": str(args.old), **key}, ensure_ascii=False, indent=1), "utf-8")
    print(f"{len(pairs)} pairs, {len(key['forfeits'])} forfeits → {blind / 'brief.md'}")
    return 0


def cmd_score(args) -> int:
    key = json.loads((ROOT / "keys" / f"{args.name}.json").read_text("utf-8"))
    new, old = (json.loads(Path(key[side]).read_text("utf-8")) for side in ("new", "old"))
    lines = (ROOT / "blind" / args.name / "verdicts.jsonl").read_text("utf-8").splitlines()
    blind = tally([json.loads(line) for line in lines if line.strip()], key)
    quoted = example_units(new["system"]) | example_units(old["system"])
    m_new, m_old = metrics(new["drafts"], quoted), metrics(old["drafts"], quoted)
    ok = compare(m_new, m_old)
    passed = blind["win_rate"] >= args.min_win and all(ok.values())
    print(f"blind: new {blind['wins']} / old {blind['losses']} / tie {blind['ties']} → win {blind['win_rate']} (≥ {args.min_win})")
    print("| metric | old | new | ok |\n|---|---|---|---|")
    for k in [*TOLERANCE, "thickness"]:
        print(f"| {k} | {m_old[k]} | {m_new[k]} | {'OK' if ok[k] else 'WORSE'} |")
    print(f"| failed | {m_old['failed']} | {m_new['failed']} | |")
    print(f"| seconds | {m_old['seconds']} | {m_new['seconds']} | ×{round(m_new['seconds'] / max(m_old['seconds'], 0.01), 2)} |")
    print("PASS" if passed else "FAIL")
    (ROOT / "keys" / f"{args.name}-score.json").write_text(json.dumps(
        {"blind": blind, "new": m_new, "old": m_old, "ok": ok, "passed": passed, "min_win": args.min_win},
        ensure_ascii=False, indent=1), "utf-8")
    return 0 if passed else 1

def _unless(text: str, instruction: str) -> str:
    """`text` without the sentences that only repeat the scene photo instruction: the 9B pasted the
    instruction into the scene copy (phase 2 spec §4)."""
    same = instruction.strip().rstrip(".!? ")
    if not same:
        return text
    lines = (" ".join(s for s in _sentences(line) if s.rstrip(".!? ") != same) for line in text.splitlines())
    return "\n".join(line for line in lines if line)

```python
def sft_rows(doc: dict, items: dict[str, dict]) -> list[dict]:
    """Teacher drafts that passed every check, as mlx-vlm rows: the runtime copy messages + the teacher's JSON (spec §5.1)."""
    if doc["system"] != prompts.COPY_SYSTEM:
        raise ValueError("drafts were checked under another COPY_SYSTEM; make them again")
    return [{"id": d["id"], "messages": [*messages(items[d["product_id"]]), {
                "role": "assistant", "content": json.dumps(d["copy"], ensure_ascii=False, separators=(",", ":"))}]}
            for d in doc["drafts"] if d["error"] is None and not d["dropped"]]


def feedback(doc: dict) -> dict[str, list[str]]:
    """Flagged sentences per product with a discarded draft: `codex_teacher.py copy --feedback` asks those once more."""
    out: dict[str, list[str]] = {}
    for d in doc["drafts"]:
        if d["dropped"]:
            out.setdefault(d["product_id"], []).extend(x["text"] for x in d["dropped"])
    return out


def cmd_sft(args) -> int:
    items = products()
    train_doc, valid_doc = (json.loads(path.read_text("utf-8")) for path in (args.train, args.valid))
    train, valid = sft_rows(train_doc, items), sft_rows(valid_doc, items)
    random.Random(0).shuffle(train)
    (ROOT / "sft").mkdir(parents=True, exist_ok=True)
    for name, rows in (("train", train), ("validation", valid)):
        (ROOT / "sft" / f"{name}.jsonl").write_text("".join(json.dumps(r, ensure_ascii=False) + "\n" for r in rows), "utf-8")
    flagged = feedback(train_doc)
    (ROOT / "feedback.json").write_text(json.dumps(flagged, ensure_ascii=False, indent=1), "utf-8")
    total = len(train_doc["drafts"])
    print(json.dumps({"train": len(train), "validation": len(valid), "teacher_drafts": total,
                      "discarded": round(1 - len(train) / max(total, 1), 3), "feedback_products": len(flagged)}))
    return 0
```
